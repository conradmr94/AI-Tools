# Sprint YYYY-MM-DD — change log

What changed in the code and why, newest first. One entry per commit or small group of commits. HH:MM is the commit time from `git log --date=format:%H:%M`, never an estimate. Decisions and progress belong in the plan, not here. Plan: [SPRINT-YYYY-MM-DD.md](./SPRINT-YYYY-MM-DD.md).

Entry format:

```
### HH:MM · <task id> · <commit(s)> · <one-line headline>
- What: the change, in a sentence.
- Why: the reason, in a sentence.
```
